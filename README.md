## 📌 About / درباره ما

**Tirex Source** is a Telegram channel and a GitHub home for **Telegram bot sources, web projects, Python tools and automation scripts**. Everything is tested, documented and free.

**تیرکس سورس** یک کانال تلگرامی و مخزن گیت‌هاب برای انتشار سورس‌کدهای **ربات‌های تلگرام، پروژه‌های وب، ابزارهای پایتون و اسکریپت‌های اتوماسیون** است. همه‌چیز تست‌شده، مستند و رایگان.

| ✅ | Our rules / قواعد ما |
|:---:|:---|
| 🔒 | Nothing is published without the source owner's permission. <br>  بدون رضایت مالک سورس، سورس منتشر نمی‌شود. |
| 📦 | Both exclusive and open-source projects, always runnable. <br> سورس‌ها هم اختصاصی و هم اوپن‌سورس — همیشه قابل اجرا. |
| 📖 | Docs in Persian + English with every project. <br>  مستندات فارسی و انگلیسی همراه هر پروژه. |
| 🚫 |  No ads, no selling, no shady links. <br>  بدون تبلیغ، بدون فروش، بدون لینک آلوده. |

> 🧠  Our goal is a clean, trustworthy archive for Persian-speaking developers.<br>
> 🧠 هدف ما ساختن یک آرشیو تمیز و قابل اعتماد برای برنامه‌نویس‌های فارسی‌زبان است.
